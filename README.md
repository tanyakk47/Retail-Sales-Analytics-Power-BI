# ☕ Coffee & Retail Sales Analytics — Power BI Dashboard

Комплексний Power BI-проєкт рівня **Marketing/Data Analyst**. Проєкт охоплює три рівні аналітичної складності — від базової звітності до порівняння даних із двох незалежних джерел (data reconciliation) — і демонструє повний цикл роботи аналітика: від сирих даних до готового інтерактивного дашборду.

**Файл дашборду:** `NBS_Test_Task.pbix` · 4 сторінки · 3 джерела даних · 25+ DAX-мір

---

## 🎯 Про проєкт

Мета проєкту — побудувати аналітичний Power BI-дашборд для ринку кави на основі трьох датасетів, дотримуючись єдиного корпоративного стилю подачі даних (кольорова палітра, сортування, форматування таблиць). Проєкт розбитий на три рівні складності, кожен з яких нарощує аналітичну глибину:

| Рівень | Фокус | Ключовий виклик |
|---|---|---|
| **Basic** | Мультивалютна звітність | Конвертація Value Sales з локальної валюти в EUR/CHF через FOREX-таблицю |
| **Intermediate** | Часові агрегації | Розрахунок MAT / YTD / MTD "з нуля" на DAX без вбудованих Time Intelligence функцій, з перемиканням валюти |
| **Advanced** | Звірка даних із двох джерел | Побудова моделі даних з двома фактовими таблицями, розрахунок розбіжностей (NCB vs MASH) з умовним форматуванням |

## 🖥️ Структура дашборду (4 сторінки)

### 1. Coffee Sales Overview *(Basic)*
Загальний огляд ринку кави з розбивкою по сегментах і країнах.
- Матриця Values Sales EUR/CHF + Volume in cups з деталізацією по Segment → AOA/EMENA/N.America
- Комбінований графік (стовпці + лінія): Values Sales EUR та Volume in cups Sales по країнах
- Treemap Top-10 виробників за Sales EUR (JDE, Nestlé, Private Label, Lavazza...)
- Area chart обсягів продажу по місяцях із трендовою лінією
- Картки Total Value Sales (EUR) та Total Volume Cups Sales
- Слайсер Segment (з винятком для карток) — **всього 0.49T EUR / 11.78bn cups**

### 2. Sales Performance *(Intermediate)*
Розрахунок ключових часових метрик "з чистого DAX" без стандартних Time Intelligence функцій.
- 3 матриці: **MAT / YTD / MTD** (This Year vs Year Ago, абсолютна та відносна зміна, частка від тотал ігноруючи фільтри — `ALL()`/`REMOVEFILTERS`)
- 3 матриці Top-5 виробників за часткою продажів (MAT / YTD / MTD)
- Картки Sales Value / MAT TY / YTD TY / MTD TY
- Слайсери Region + Currency (EUR/CHF), синхронізовані з наступною сторінкою

### 3. Country Sales Analysis *(Intermediate)*
Географічний зріз динаміки продажів.
- Стовпчиковий графік MAT TY по місяцях 2020 з підсумковим стовпцем MAT
- Filled Map з інтерактивним вибором країн
- Комбінований лінійно-стовпчиковий графік: Sales MAT TY + Share MAT TY по країнах

### 4. NCB vs MASH *(Advanced)*
Звірка розходжень між двома джерелами даних по 5 країнах (Brazil, Egypt, Japan, Spain, UK).
- Лінійний графік % Difference по місяцях з **умовним кольором маркерів** (🔴 >10% · 🟡 5–10% · 🟢 <5%)
- Горизонтальна стовпчикова діаграма з підписами формату `Country: % Difference`
- Порівняльний графік NCB vs MASH ліній з візуалізацією абсолютного розходження
- Матриця Country × Month Year з градієнтним умовним форматуванням за абсолютною розбіжністю
- Картка з переліком активних фільтрів сторінки
- Слайсери: Player, MAT Data Ending, Country, Periods (MAT / MAT LY / YTD / YTD LY)

**Ключовий інсайт сторінки:** сукупне розходження між джерелами становить **-$25.8M (-11.1%)**, найбільше — по Єгипту (-16.86%), найменше — по Бразилії (-4.31%).

## 🛠️ Технічний стек

- **Power BI Desktop** — модель даних, DAX, візуалізація
- **DAX** — Time Intelligence "з нуля" (MAT/YTD/MTD без стандартних функцій), `REMOVEFILTERS`/`ALLSELECTED` для розрахунку часток незалежно від фільтрів, змінні (`VAR`) для перемикання валют і періодів
- **Data Modeling** — зіркова схема з двома фактовими таблицями (NCB, MASH), календарна таблиця як основна дата-таблиця, звʼязки dimension ↔ fact
- **Power Query (M)** — трансформація та очищення вихідних CSV/XLSX перед завантаженням у модель

---

## 💡 Ключові аналітичні прийоми

- Побудова MAT/YTD/MTD показників власними DAX-формулами (без CALENDAR Time Intelligence) — розуміння механіки, а не лише синтаксису
- Динамічне перемикання валюти та періоду через слайсери, що впливають одразу на кілька візуалів на сторінці
- Розрахунок "частки від загального" (Share), що ігнорує локальні фільтри — класичний патерн `REMOVEFILTERS` для порівняння сегмента з ринком у цілому
- Умовне форматування на основі порогових значень (колір маркера/підпису залежно від % відхилення)
- Групування категорій (обʼєднання Ready to Drink + Roast & Ground) без втрати деталізації по решті сегментів
- Витриманий корпоративний стиль дашборду (кольорова гама, сортування, розташування "Totals" зверху) — навичка роботи в межах брендбуку/дизайн-гайду

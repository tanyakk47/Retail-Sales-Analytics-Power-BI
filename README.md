# Coffee & Retail Sales Analytics — Power BI Dashboard

Комплексний Power BI-проєкт рівня **Data Analyst**. Проєкт охоплює три рівні аналітичної складності — від базової звітності до порівняння даних із двох незалежних джерел (data reconciliation) — і демонструє повний цикл роботи: від сирих даних до готового інтерактивного дашборду.

  **Файл дашборду:** `Retail_Sales_Analytics.pbix` · 4 сторінки · 3 джерела даних

---

## Про проєкт

Мета проєкту — побудувати аналітичний Power BI-дашборд для ринку кави на основі трьох датасетів. Проєкт розбитий на три рівні складності, де кожен наступний етап розширює попередній і додає складніші розрахунки та аналітичні задачі:

| Етап | Задача | Що реалізлвано |
|---|---|---|
| **Basic** | Мультивалютна звітність | Конвертація Value Sales з локальної валюти в EUR/CHF через FOREX-таблицю |
| **Intermediate** | Часові агрегації | Розрахунок MAT / YTD / MTD "з нуля" на DAX без вбудованих Time Intelligence функцій, з перемиканням валюти |
| **Advanced** | Звірка даних із двох джерел | Побудова моделі даних з двома фактовими таблицями, розрахунок розбіжностей (NCB vs MASH) з умовним форматуванням |

## Визначення періодів (MAT / YTD / MTD)

| Термін | Визначення |
|---|---|
| **MAT TY** (Moving Annual Total, This Year) | Сума значень за останні 12 місяців, що завершуються останнім доступним періодом поточного року. Напр., якщо останній доступний період — листопад 2020, то MAT TY = сума з 1 грудня 2019 по 30 листопада 2020 |
| **MAT YA** (Moving Annual Total, Year Ago) | Сума за ті самі 12 місяців, але роком раніше. Напр., MAT YA = сума з 1 грудня 2018 по 30 листопада 2019 |
| **YTD TY** (Year to Date, This Year) | Сума значень з 1 січня поточного календарного року до останнього доступного місяця/дати. Напр., 1 січня 2020 – 30 листопада 2020 |
| **YTD YA** (Year to Date, Year Ago) | Сума за той самий період (з початку року до тієї ж дати), але роком раніше. Напр., 1 січня 2019 – 30 листопада 2019 |
| **MTD TY** (Month to Date, This Year) | Сума значень за останній доступний місяць. Напр., 1–30 листопада 2020 |
| **MTD YA** (Month to Date, Year Ago) | Сума за той самий місяць, але роком раніше. Напр., 1–30 листопада 2019 |

## Структура дашборду (4 сторінки)

### 1. Coffee Sales Overview *(Basic)*
Загальний огляд ринку кави з розбивкою по сегментах і країнах.
- Матриця Values Sales EUR/CHF + Volume in cups з деталізацією по Segment → AOA/EMENA/N.America
- Комбінований графік (стовпці + лінія): Values Sales EUR та Volume in cups Sales по країнах
- Treemap Top-10 виробників за Sales EUR (JDE, Private Label, Lavazza...)
- Area chart обсягів продажу по місяцях із трендовою лінією
- Картки Total Value Sales (EUR) та Total Volume Cups Sales
- Слайсер Segment (з винятком для карток) — **всього 0.49T EUR / 11.78bn cups**

### 2. Sales Performance *(Intermediate)*
Розрахунок ключових часових метрик "з чистого DAX" без стандартних Time Intelligence функцій.
- Три матриці: **MAT / YTD / MTD** (This Year vs Year Ago, абсолютна та відносна зміна, частка від тотал ігноруючи фільтри)
- Три матриці Top-5 виробників за часткою продажів (MAT / YTD / MTD)
- Картки Sales Value / MAT TY / YTD TY / MTD TY
- Слайсери Region + Currency (EUR/CHF), синхронізовані з наступною сторінкою

### 3. Country Sales Analysis *(Intermediate)*

- Стовпчиковий графік MAT TY по місяцях 2020 з підсумковим стовпцем MAT
- Filled Map з інтерактивним вибором країн
- Комбінований лінійно-стовпчиковий графік: Sales MAT TY + Share MAT TY по країнах

### 4. NCB vs MASH *(Advanced)*
Звірка розходжень між двома джерелами даних по 5 країнах (Brazil, Egypt, Japan, Spain, UK).
- Лінійний графік % Difference по місяцях з **умовним кольором маркерів** (🔴 >10% · 🟡 5–10% · 🟢 <5%)
- Горизонтальна стовпчикова діаграма з підписами формату `Country: % Difference`
- Порівняльний графік NCB vs MASH ліній з візуалізацією абсолютного розходження
- Матриця Country × Month Year з градієнтним умовним форматуванням за абсолютною розбіжністю
- Картка з переліком активних фільтрів сторінки
- Слайсери: Player, MAT Data Ending, Country, Periods (MAT / MAT LY / YTD / YTD LY)
